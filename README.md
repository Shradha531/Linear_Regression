# 🏠 House Price Prediction Using Linear Regression

## 📌 Project Overview
This project uses Machine Learning and Multiple Linear Regression to predict house prices based on different property features.

## 🎯 Objective
The main objective is to develop a model that predicts house prices using property information such as area, bedrooms, bathrooms, stories, parking and other facilities.

## 📊 Dataset Information
- **Dataset:** Housing.csv
- **Total Records:** 545
- **Total Columns:** 13
- **Target Variable:** price

### Features
- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📈 Model Evaluation
The model performance is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared Score (R²)

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Open Google Colab.
3. Upload the Housing.csv dataset.
4. Open the project notebook.
5. Run all code cells.

## 📝 Conclusion
This project demonstrates the application of Multiple Linear Regression in predicting house prices. It helps understand data preprocessing, visualization, model training and performance evaluation.
